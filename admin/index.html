How to start

The same notes are in admin/README.md.

  1. From the hustix-alpha directory, run python3 admin/server.py.
  2. Open http://127.0.0.1:3090. This console is port 3090.
  3. Sign in with ADMIN_PASSWORD from admin/.env. The first start writes that file.
  4. Use Services to start the frontend on port 3000 and the backend on port 8000.

Advisor management is http://127.0.0.1:3000/admin after both of those are running. Logs are admin/logs/frontend.log and admin/logs/backend.log.
